Features

Everything you need to answer “what's working?”

One dashboard for traffic, conversion and user feedback, instead of three tools that each copy your visitors' data.

Real-time overview

Visitors, visits, pageviews, bounce rate and duration, compared against the previous period.

Channel attribution

Traffic grouped into direct, search, social, referral and paid, with per-source drill-down.

Funnels

Build multi-step funnels from pages and events and see exactly where visitors drop off.

Session replays

Watch real sessions to debug UX issues. Form inputs are masked before they leave the browser.

User timelines

Call identify() to follow one user's pageviews, events and survey answers on one timeline.

In-app surveys

Show a short survey when a chosen event fires, once per visitor. Answers sit next to your analytics.

Short links

Create short links and see clicks by country and referring site.

Bot detection

Crawlers and headless browsers are flagged automatically, so numbers reflect real people.

Geo & devices

Countries from a local GeoIP database plus browsers, OS and devices, with no external lookups.

Privacy by construction

Analytics your visitors don't have to trust a third party for.

Siraaj runs on your infrastructure. There is no Siraaj cloud receiving copies of your data: events go from the browser to your server and stop there.

  • No cookies, no cross-site tracking

    Visitors are counted without third-party cookies or cross-site identifiers.

  • Your server, your database

    Everything lives in a single DuckDB file you can back up, inspect or delete.

  • Per-project, revocable keys

    Each site sends events with its own tracking key. Revoke one and that site stops reporting.

  • Isolated accounts

    Every dashboard query is scoped to the projects you own.

Get started

Running in two steps.

Start the server, create a project in the dashboard to get a tracking key, then add the SDK to your site.

Read the docsView source

1Run the server

# Dashboard at http://localhost:8080/dashboard
docker run -d -p 8080:8080 \
  -v $(pwd)/data:/data \
  mohamedelhefni/siraaj

2Add the SDK

// npm install @hefni101/siraaj
import { analytics } from '@hefni101/siraaj';

analytics.init({
  apiUrl: 'https://analytics.example.com',
  projectId: 'my-site',
  trackingToken: 'siraaj_trk_…'
});
